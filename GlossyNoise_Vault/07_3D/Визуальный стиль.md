- **Текстуры:** Krita (пиксель-арт, дизеринг, vertex color).
- **AI-генерация моделей:** отменена. Нейронка — только для текстур.

> **⚠️ ПРАВИЛО ПРОРАБОТКИ АССЕТОВ И МИКРО-МЕШИНГА:**
> **Никаких ленивых примитивов и монолитных кубов!**
> - Каждая модель создается через **микро-мешинг** — детальную сборку из множества мелких геометрических элементов (пластин, брусков, скосов, утопленных ниш).
> - Никаких попыток «вырезать» детали внутри цельного куба.
> - Физическая детализация мелких узлов (кнопки, швы, бортики, рамы, разъёмы) обязательна для каждого прописанного ассета.
> - **Оптимизация:** Low Poly (куб = 12 трисов), объединение статики в Blender (`Ctrl + J`), отказ от тяжёлого запекания — производительность остаётся высокой.

## 💡 Технические рекомендации по моделированию

### 1. Фаски (Bevels)
Направляй фаски на углы! В стиле *Hello Neighbor* почти нет идеальных 90-градусных острых углов — все объекты слегка «мягкие» и обтекаемые.

### 2. Текстурные карты
- На **физическом окружении** (стол, стены) используй **матовые Roughness-карты**.
- На **девайсах Y2K** задирай **Specular** и понижай **Roughness**, чтобы получить **острые глянцевые блики**.

### 3. UV-Развёртка
Сделай **текстолитовые платы** и **экраны гаджетов** максимально крупными на UV-сетке, чтобы при приближении лупы тексты и микросхемы оставались чёткими.

## 🧱 Blockbench: специфика и возможности

**Blockbench — не «майнкрафт-кубики».** Это полноценный low-poly редактор с широкими возможностями:

### Что можно делать
- **Вращение блоков** — наклонные грани, трапеции, повороты.
- **Кастомные углы наклона** — «пузатость», скругления, утрированные формы.
- **Работа с вершинами** — точная подгонка геометрии.
- **Low-poly органика** — призёры конкурсов делают персонажей, существ, сцены.
- **Пиксель-арт прямо по граням** — без классической UV-развёртки.

### Уровень референсов
- **AnzSama** — 2 места в конкурсах (Underwater, Food).
- **Wanwin** — 5,707 голосов, 9 сабмишенов, призовые места (Cozy Cabin, Aviation, Trains, Food).
- **土豆废弃物** — 3 место в Food.
- Ссылки: https://contests.blockbench.net/artists/

### Наш подход
- **Blockbench** — основной редактор (80% моделей).
- **Blender** — технический мост (Origin, объединение, габариты, экспорт `.glb`).
- **Стиль:** Crunchy Y2K, chunky-формы, утрированные силуэты.
- **Экспорт:** `.glb`, Scale 0.01 (1 пиксель = 1 см), +Y Up.

### Технические моменты
- **Масштаб:** 1 пиксель = 1 см. Габариты CRT-монитора: 44 × 46 × 42 пикселя = 0.44 × 0.46 × 0.42 м.
- **Текстуры:** пиксель-арт прямо по граням (32×32, 64×64, 128×128).
- **Экспорт:** `.glb` с Scale 0.01.
- **Ограничения:** сложная органика (рука Управдома) — лучше Blender или CC0. (но если совсем уж никак)

### Работа с формами и UV

**Примитивы (не только кубы):**
- **Цилиндр** (8–12 граней) — корпуса, подставки, ручки, трубы.
- **Сфера** (сплюснутая) — выпуклые CRT-экраны, линзы.
- **Mesh-редактор** — произвольные формы (перемещение вершин, экструзия).
- **Куб** — только для прямоугольных элементов (планки, панели, кнопки).

**UV на сложных формах:**
- На цилиндрах и сферах пиксель-арт **может «плыть»** (пиксели тянутся по UV).
- **Решение:** контроль UV вручную (Per-Face UV), правка меша.
- Связка **DeepSeek + Гемини** позволяет контролировать процесс.

**Запрет на «лестницу из кубов»:**
- Плавные переходы — только через цилиндры, сферы, Mesh.
- 5 кубов подряд — не плавно, а ступенчато.

### Стандарт разрешения текстур

**База:** 256×256.
**Точечно:** 512×512 для конкретных задач.
**Мелочь:** 128×128 для мелких деталей.

| Элемент | Разрешение |
|---------|------------|
| Корпус (пластик) | 256×256 |
| Рамка, планки | 256×256 |
| Кнопки OSD | 128×128 или 256×256 |
| Вентиляционные щели | 128×128 |
| Стикер | 256×256 (или 512, если текст нечитаем) |
| **Экран CRT** | **512×512** |
| Подставка | 256×256 |

**Правила:**
- Все текстуры — степень двойки (128, 256, 512, 1024).
- Не гонимся за 512×512 на всё (Y2K — пиксель-арт, не реализм).
- Не делаем 1024×1024 (перебор по памяти).
- Начинаем с 256×256, смотрим в Godot, увеличиваем точечно.

## 🎨 Пайплайн текстур: Фотобашинг (Photobashing)

**Утверждено:** Для текстур корпуса (и других моделей) используем **чистокровный фотобашинг** через Krita. **Не** стандартные генераторы текстур.

**Почему:**
- **Аутентичность:** реальный пожелтевший пластик — сложная текстура (микротрещины, пятна, зерно). Генераторы не дают такого.
- **Стиль Y2K:** ретро-железо, потрёпанное временем.
- **Контроль:** ты решаешь, где царапина, где грязь, где блик.
- **Экономия:** реальные фото — бесплатно.

**Процесс:**
1. **Поиск фото:** свои фото (старый пластик), CC0-базы (Unsplash, Pexels, Poly Haven), сканы.
2. **Обработка в Krita:** импорт → подгон под 256×256 (или 512×512) → кроп → цветокоррекция (под палитру `#C2BCB0`) → убрать лишнее.
3. **Фотобашинг (на UV):** натянуть фото на UV → дорисовать кистями (царапины, грязь, потёртости по углам) → добавить зерно.
4. **Экспорт:** PNG (256×256 или 512×512) → импорт в Blockbench/Blender → натянуть на модель.

**Исключение:** Экран CRT — фотобашинг для базовой текстуры, но динамика (статика, Глитчи, искажения) — через шейдер (позже).


## 🧩 Пайплайн: готовые модели CC0 + адаптация

**Утверждено:** Для сложных 3D-моделей (включая CRT-монитор) используем готовые модели CC0 с последующей адаптацией под стиль. Не делаем модели с нуля (если это не просто).

**Почему:**
- 3D-моделирование и UV — не зона автора (геймдизайнер, программист, продюсер).
- Готовые модели (CC0) — уже с UV, текстурами, оптимизацией.
- Адаптация (цвет, текстуры, детали) — проще и быстрее.
- Это норма для инди-разработки (Valheim использовал аутсорс и готовые ассеты).

**Процесс:**
1. **Поиск готовой модели:** Sketchfab (CC0), Kenney, Quaternius. Проверка лицензии.
2. **Адаптация под стиль:** цвет (палитра `#C2BCB0`), текстуры (фотобашинг в Krita), детали (кнопки, стикер — свои), пропорции (масштаб в Blender).
3. **Экспорт в Godot:** через Blender (импорт → экспорт `.glb`). Проверка масштаба, материалов, коллизий.

**Что можно менять:**
- Цвет, материалы.
- Пропорции, масштаб.
- Добавлять детали (кнопки, царапины, стикеры).
- Удалять лишнее.
- Перекрашивать текстуры (фотобашинг).

**Что сложно/невозможно:**
- Полностью переделать геометрию (без ретопологии).
- Поменять UV-развёртку (сложно).

**Исключение:** Простые модели (куб, цилиндр, кнопка) — можно делать в Blockbench (Auto UV).
