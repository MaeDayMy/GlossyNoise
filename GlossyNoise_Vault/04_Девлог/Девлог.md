## 📝 DEVLOG ENTRY #05 | PROJECT GLOSSY NOISE

**Дата:** 09.09.2026

**Статус билда:** Pre-Alpha / RayCast Mechanics & Reverse Assembly Loop

### 1. Диагностика и причина конфликта Area3D

- **Проблема перехвата кликов:** Коллизия крышки (`Cover`) перекрывала невидимые `Area3D` винтов при попытке закрутить их обратно.
    
- **Архитектурный вердикт:** Отказ от встроенных сигналов `_input_event` на `Area3D` узлов в пользу централизованной системы **RayCast3D** с камеры.
    

### 2. Переход на RayCast3D с камеры

- **Точный контроль пересечений:** Обработка клика перенесена в RayCast-систему (`intersect_ray`) с явными приоритетами (Винт ➔ Крышка ➔ Сокет).
    
- **Логика обратной сборки:** Клик по винту при установленной крышке забирает винт из инвентаря и закручивает его обратно.
    
- **Защита от заклинивания:** Добавлена проверка `is_repaired == true` при попытке вернуть крышку на место.
    

### 3. Текущее состояние и следующий шаг

- Переход на `RayCast3D` утверждён и реализован.
    
- Проверка полной цепочки ремонта перед переходом к Конвейеру заказов.

## 📝 DEVLOG ENTRY #08 | PROJECT GLOSSY NOISE

**Дата:** 13.09.2026

**Статус билда:** Pre-Alpha / CORE LOOP COMPLETE! 🎉

### 1. Главное достижение: Рабочий Core Loop

Полностью замкнут основной игровой цикл ремонта пейджера:

1. Откручивание 4 винтов ➔ инвентарь.
    
2. Авто-сдвиг крышки ➔ открытие планки и гнезда.
    
3. Клик по гнезду ➔ вставка батарейки ➔ `is_repaired = true`.
    
4. Клик по крышке ➔ возврат на место.
    
5. Закручивание 4 винтов из инвентаря ➔ `is_assembled = true`.
    
6. Клик по пневмотрубе ➔ отправка девайса ➔ +$50.
    

### 2. Финальная архитектура взаимодействия

- `click_manager.gd` (на `Camera3D`) — обработка через `intersect_ray`.
    
- `device.gd` (на `Device`) — центральная логика взаимодействия.
    
- **Решение:** Крышка сдвигается в сторону, не скрываясь из кадра.
